# Titre du premier article

Auteur : Initiale. Nom

Rubrique : Cas d'ici et d'ailleurs

Relecture : Initiale. Nom

Écrivez chaque article sous un titre au style « Titre 1 ». Juste en dessous, une ligne « Auteur : … » ; si vous le souhaitez, une ligne « Rubrique : … » (Cas d'ici et d'ailleurs, Littérature, Infos des Autorités de Santé : le sommaire regroupe les articles par rubrique) et une ligne « Relecture : … ». Le texte s'écrit normalement : **gras**, *italique*, listes à puces ou numérotées. La mise en page, les couleurs et la taille du texte se font toutes seules.

::: {custom-style="Encadré"}
Un paragraphe au style « Encadré » devient un encadré : le message clé de l'article.
:::

[saut de colonne]

Un paragraphe « [saut de colonne] » coupe l'article en deux colonnes à cet endroit. Sans lui, l'article tient sur une colonne, et le texte s'agrandit tout seul pour remplir la page.

[En pratique]{custom-style="Intertitre en ligne"} le style de caractères « Intertitre en ligne » ouvre un paragraphe par quelques mots en couleur.

Une image s'insère avec, juste en dessous, sa légende au style « Légende de figure », et son texte de remplacement (clic droit, « Modifier le texte de remplacement »), lu par les lecteurs d'écran.

::: {custom-style="Source"}
Source : un paragraphe au style « Source » donne la source officielle de l'article (courrier de l'ANSM et sa date), en petits caractères.
:::

# Les types de blocs

Auteur : Initiale. Nom

Rubrique : Littérature

Chaque type de contenu a son style « Bloc … » : le bulletin en fait un encadré titré, dans sa couleur. Plusieurs paragraphes à la suite dans le même style forment un seul bloc.

::: {custom-style="Bloc Cas clinique"}
« Bloc Cas clinique » : le récit d'un cas (âge, traitement, évolution), séparé du commentaire.
:::

::: {custom-style="Bloc À retenir"}
« Bloc À retenir » : les messages à retenir de l'article.
:::

::: {custom-style="Bloc En pratique"}
« Bloc En pratique » : la conduite à tenir, les recommandations.
:::

::: {custom-style="Bloc Le saviez-vous ?"}
« Bloc Le saviez-vous ? » : une information à côté du sujet, un rappel.
:::

::: {custom-style="Bloc Mécanisme"}
« Bloc Mécanisme » : le mécanisme d'action ou de l'effet indésirable.
:::

[saut de colonne]

::: {custom-style="Bloc Attention"}
« Bloc Attention » : une mise en garde, une erreur à éviter, un « never event ».
:::

::: {custom-style="Bloc Pour les patients"}
« Bloc Pour les patients » : les conseils à donner aux patients.
:::

::: {custom-style="Bloc Pour les pharmaciens"}
« Bloc Pour les pharmaciens » : ce que doivent faire les pharmaciens.
:::

::: {custom-style="Bloc Pour les prescripteurs"}
« Bloc Pour les prescripteurs » : ce que doivent faire les prescripteurs.
:::

::: {custom-style="Bloc Annonce"}
« Bloc Annonce » : un webinaire, une enquête, une nouveauté du réseau.
:::

Pour créer votre propre type : onglet Accueil, volet Styles, bouton « Nouveau style ». Nommez-le « Bloc » suivi de son titre (par exemple « Bloc Interaction »), type Paragraphe, basé sur Normal, et choisissez sa couleur de police : le bulletin en fait un bloc titré « Interaction », dans cette couleur (assombrie si besoin pour rester lisible).

## Une brève

Le style « Titre 2 » fait un intertitre dans l'article : plusieurs informations courtes peuvent tenir sous un même « Titre 1 », chacune sous son « Titre 2 ».

# À retenir

Auteur : Initiale. Nom

Le dernier article reprend le message clé.

Pour citer un article, écrivez son PMID ou son DOI entre crochets, là où vous le citez : [PMID 14999113] ou [DOI 10.1136/postgradmedj-2020-138661]. Le numéro d'appel et la référence complète s'ajoutent tout seuls, dans l'ordre de citation, sur une page « Références » à la fin du bulletin. Pour une source sans identifiant (site, document interne) : [Réf : CredibleMeds. https://www.crediblemeds.org].

Si vous préférez taper les références vous-même, numérotez les appels en exposant et écrivez la liste au style « Références » (sans crochets dans le texte, pour ne pas mélanger les deux numérotations) :

::: {custom-style="Références"}
1\. Référence tapée à la main.
:::
